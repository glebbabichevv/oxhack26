# Design reference (internal)

Screenshots of our earlier product, kept only as a **visual reference** for Horizon. They show an old brand name and old copy: never copy names, logos, copy or imagery into the Horizon UI. The spec is `/DESIGN.md`.

**Remove this folder before the repo goes public on Devpost** (TASKS.md has the item).

| File | What to take from it |
|---|---|
| `dashboard-light.png` | **The target.** Hairline Ledger grid, KPI strip, Poppins numbers, green trend pills, graphite gradient bars, stepped lines (here orange: ours is ink + ash), table rows, outline pill button, header breadcrumb. |
| `dashboard-warm.png` | Same layout on a warm background with ink + grey stepped lines: exactly our two-series chart colours. Don't take the warm background. |
| `landing-hero.jpg` | Dark pill CTA with arrow, muted one-line trust row, the table inside the browser mock (uppercase muted column heads, right-aligned numbers, value cells). |
| `landing-features.jpg` | Chart card with a ink curve vs dashed grey curve + small mono formula chip: the look for our calibration chart and its tooltip. |
| `landing-use-cases.jpg` | Inputs (pill fields, muted uppercase labels), black pill submit, clean data table. |
| `landing-pricing.jpg` | Segmented control (Monthly / Annual pill toggle), small dark "Your plan" badge. Use the toggle for horizon tabs (30d / 7d / 3d / 1d / 12h). |
| `landing-faq-footer.jpg` | Accordion rows with hairline dividers and + icons, footer column type. |
| `landing-cli-hero.jpg` | Phone/chat mock: only if we need a mobile mock in the pitch. |

Not for the dashboard: the painting backgrounds, the Greek meander divider, italic headline words, spaced-out eyebrow labels and 01/02 numbers (marketing devices, banned on our data screen by DESIGN.md).
