# Design reference (internal)

Fresh screenshots (24 Oct 2026, 1440×900) of the **current** versions of our earlier landing site and Chrome extension, as a visual reference for Horizon. They show an old brand name and old copy: never copy names, logos, copy or imagery into the Horizon UI. The spec is `/DESIGN.md`.

**Remove this folder before the repo goes public on Devpost** (TASKS.md has the item).
